# 양평동교회 회계 V13 — 개인 모바일용

개인이 휴대폰에서 회계자료를 입력·조회·백업하고 영수증 OCR/공유 기능을 사용할 수 있도록 정리한 V13 패키지입니다.

## 포함
- Android 빌드용 프로젝트
- iPhone/Capacitor 프로젝트
- PWA 웹앱
- 영수증 사진 가져오기 및 OCR(최종 확인 필수)
- 수입·지출·예산·결재·회계검증·결산 기능
- CSV/JSON 백업 및 모바일 공유

## 개인 모바일 사용
- 기본 회계 데이터는 기기 로컬 저장을 우선 사용합니다.
- 여러 사람이 동시에 같은 장부를 사용하는 공동회계는 Firebase 등 별도 서버 설정이 필요합니다.
- 실제 APK/IPA는 Android SDK/Apple Xcode 빌드 및 서명이 필요합니다.

## Android
`android-ready` 폴더가 실제 APK 빌드 대상입니다. GitHub Actions의 `build-apk.yml`을 사용할 수 있습니다.

## 주의
OCR 결과는 오인식할 수 있으므로 저장 전에 날짜·금액·거래처를 반드시 사람이 확인하세요.
