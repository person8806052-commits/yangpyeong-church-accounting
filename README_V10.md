# 양평동교회 회계 V10

V9의 개인 모바일·카카오톡 공유·영수증 OCR 기능을 유지하면서 회계검증센터와 데이터 저장 키 분리를 추가한 프로젝트입니다.

## V10 추가 사항
- 전용 저장 키 `ypdc_accounting_v10` 사용
- V9/V4/V3 데이터 자동 마이그레이션
- 전체 백업 파일명 V10으로 정리
- 회계검증센터: 날짜/구분/금액/계정 연결/거래내용 누락 점검
- 중복 가능 거래 탐지
- 결재 미완료 거래 확인
- 영수증 연결 끊김 확인
- 검증 결과 출력
- 기존 OCR의 사람 확인 후 저장 원칙 유지

## 반드시 확인할 점
- 이 프로젝트는 소스/빌드 프로젝트입니다. 이 환경에서는 서명된 APK/IPA를 직접 만들 수 없습니다.
- Firebase 실시간 공동회계는 실제 Firebase 프로젝트와 보안규칙 설정이 필요합니다.
- OCR은 브라우저에서 Tesseract.js를 불러오는 방식이므로 최초 OCR 사용 시 인터넷이 필요할 수 있고 인식 결과는 반드시 원본 영수증과 대조해야 합니다.
- Android/iPhone 앱 배포는 각 플랫폼의 빌드·서명 환경이 필요합니다.

## 권장 운영
1. 거래 입력
2. 영수증 첨부/OCR
3. 사람이 원본 대조
4. 결재 진행
5. V10 회계검증
6. 전체 백업
7. 결산 출력
