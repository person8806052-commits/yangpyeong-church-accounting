V9 영수증 OCR 자동인식

영수증 사진에서 날짜·금액·상호 후보를 읽어 입력값으로 제안합니다. OCR 결과는 반드시 사람이 확인한 뒤 장부에 저장됩니다.

OCR 확인 원칙

  • 인식된 금액·날짜·상호는 후보값입니다.
  • 저장 전 영수증 원본과 반드시 대조합니다.
  • 인터넷이 가능한 경우 브라우저 OCR 엔진을 불러옵니다.
  • 인터넷이 없으면 사진 첨부만 하고 수동 입력할 수 있습니다.

V7 관리자센터

V8 카카오톡·개인모바일 센터

카카오톡으로 영수증 가져오기

카카오톡에서 받은 영수증 사진을 이 화면의 사진 선택으로 가져오면 지출 입력 화면에 자동 첨부합니다. 금액과 거래내용만 확인하면 됩니다.

카카오톡으로 회계자료 보내기

휴대폰의 공유 화면을 열어 카카오톡을 선택하면 됩니다.

개인 모바일 안전관리

  • 영수증 사진은 거래와 연결하여 관리합니다.
  • 카카오톡 전송 전 개인정보·계좌번호 등 민감정보가 포함됐는지 확인하세요.
  • 중요 자료는 카카오톡만 보관하지 말고 전체 백업파일을 별도로 보관하세요.

V12 휴대폰 설치·운영센터

Android APK·iPhone 앱·홈 화면 설치를 위한 현재 상태와 운영 점검을 한 곳에서 확인합니다.

휴대폰 사용 방법

  1. Android: APK를 빌드한 뒤 휴대폰에서 설치합니다.
  2. iPhone: Xcode로 iOS 앱을 빌드하고 TestFlight 또는 App Store로 설치합니다.
  3. 가장 간단한 방법: PWA를 웹에 배포한 뒤 브라우저에서 ‘홈 화면에 추가’를 사용합니다.

현재 이 프로젝트에는 서명된 APK/IPA가 포함되어 있지 않습니다. Android SDK와 Apple 개발환경에서 최종 빌드·서명이 필요합니다.
