# 양평동교회 회계 V11

V10의 영수증 OCR·회계검증을 유지하면서 실무 회계관리센터를 추가한 프로젝트입니다.

### 추가 기능
- 수입·지출·잔액 KPI
- 결재 단계별 현황
- 영수증 증빙 연결 현황
- 계정별 예산 대비 집행률
- 12개월 수입·지출·누적잔액
- 회계연도 결산 상태 표시 및 결산 전 전체백업
- 회계 검토자료 CSV
- 실무관리 보고서 인쇄

### 검토 결과
- HTML/JavaScript 문법 점검 완료
- V10 기반 파일 구조 유지
- Android/iPhone/PWA 빌드 프로젝트 형태 유지

### 한계
서명된 APK/IPA는 포함하지 않았습니다. 이 실행환경에는 Android SDK·Xcode가 없어 실제 스토어/기기용 서명 빌드를 수행할 수 없습니다. Firebase도 별도 프로젝트 설정이 필요합니다.
