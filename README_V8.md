# 양평동교회 회계 V8

개인 모바일에서 회계자료를 작성하고 카카오톡으로 보내거나, 카카오톡에서 받은 영수증 사진을 회계 앱으로 가져오는 버전입니다.

## 핵심
- Android / iPhone / PWA
- V7 회계기능 유지
- V8 공유센터
- Web Share API를 통한 휴대폰 공유 메뉴 → 카카오톡 선택
- 회계요약/CSV/전체백업 공유
- 영수증 사진 선택 → 지출 입력화면 자동 첨부
- Android 네이티브 `ACTION_SEND image/*` 수신 구조 추가: 카카오톡/갤러리 등에서 "양평동교회 회계"를 공유 대상으로 선택 가능
- 공유받은 영수증은 지출 입력 화면에 자동 첨부
- 민감정보가 포함된 영수증은 공유 전 확인하도록 안내

## 사용 예
1. 카카오톡에서 영수증 사진을 받음
2. 사진을 열고 공유 → 양평동교회 회계
3. V8이 열리면 `공유받은 사진 불러오기`
4. 지출 입력 화면에서 금액·거래내용·관항목을 확인
5. 저장 → 장부/영수증철에 연결

## iPhone 주의
iOS에서 다른 앱의 공유 시트에 앱을 표시하려면 Xcode에서 Share Extension 또는 공유 대상 등록을 추가해야 합니다. 이 프로젝트에는 웹/PWA 공유 기능이 포함되어 있으며, App Store용 완전한 iOS Share Extension은 macOS/Xcode에서 앱 타깃과 App Group을 설정해야 합니다.

## 중요한 한계
- 사진에서 금액/상호/날짜를 자동으로 OCR 판독하는 기능은 아직 넣지 않았습니다. OCR을 넣을 경우 오인식 방지를 위해 사용자가 최종 확인해야 합니다.
- 실제 여러 사람의 공동회계 서버 동기화는 Firebase 설정이 별도로 필요합니다.
- 이 환경에서는 서명된 APK/IPA를 생성하지 않았습니다.
