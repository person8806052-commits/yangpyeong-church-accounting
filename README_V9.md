# 양평동교회 회계 V9

개인 모바일 회계 + 카카오톡 공유 + 영수증 OCR 확인형 버전입니다.

## V9 핵심
- Android / iPhone / PWA
- V8의 개인 모바일·카카오톡 공유·영수증 가져오기 유지
- 영수증 사진 OCR(브라우저에서 Tesseract.js를 불러오는 온라인 방식)
- OCR 결과에서 날짜·금액·상호 후보 자동 추출
- 결과를 사용자가 확인한 후 지출입력으로 전송
- OCR 원문 확인 가능
- OCR 실패/오프라인 시 사진 첨부 + 수동 입력으로 안전하게 전환

## 중요한 회계 원칙
OCR 결과를 자동으로 확정하지 않습니다. 반드시 원본 영수증과 대조하고 사용자가 확인한 뒤 장부에 저장합니다.

## 사용
1. 카카오톡에서 받은 영수증을 앱으로 공유하거나 V9 화면에서 사진 선택
2. 영수증 OCR 실행
3. 날짜·금액·상호 후보 확인
4. '확인 후 지출입력으로 보내기'
5. 관·항·목, 부서, 결재상태 확인
6. 저장

## 한계
- OCR 엔진은 CDN에서 로드되므로 최초 OCR에는 인터넷이 필요합니다.
- OCR 인식률은 영수증 품질·기울기·글꼴에 따라 달라집니다.
- 실제 APK/IPA 서명은 Android Studio/Xcode가 필요합니다.
